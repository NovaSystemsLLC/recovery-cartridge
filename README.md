# Nova Systems Recovery Cartridge
> _It's a recovery cartridge. You need a code from a machine to use it._

This repo contains the source code for a Wherigo cartridge. This cartridge is not linked to a physical or virtual Geocache, and you do not need to travel to play it. You will however, need extra information from outside the cartridge to play it.

# How to Play
## Android
1. Create a Geocaching account if you do not already have one.
2. Download [c:geo](https://www.cgeo.org/) via the Play Store, F-Droid, or via APK file.
3. Follow through with setup. You do not need to log in with your Geocaching account.
4. Once in the main app, select the three dots in the top right and choose "Wherigo Player".
5. Choose the 2nd control icon (cloud with downwards pointing arrow) and enter the Wherigo cartridge ID below:
```
305e2634-214d-4f9f-8f74-aca89a588948
```
6. You'll be asked to sign in to your Geocaching account, whether you signed in previously or not. Follow the steps given by the app.
7. A "not logged in" error will show up. Ignore it - you are logged in. Re-fetch the cartridge by entering the cartridge ID into the same menu.
8. Start playing.

## iOS
> [!NOTE]  
> I do not currently have an iPhone to write instructions for. It is possible to play this cartridge on an iPhone running iOS 11.0 or later via the [Wherigo](https://apps.apple.com/us/app/wherigo/id1538051913) app, however you are on your own for figuring out how to load cartridges.

## One of those old Garmin devices
I beg you. Please use a phone. I will not give support if you decide to load the cartridge there. You don't need instructions on how to load the cartridge anyways, probably.

## Any other OS/device
Wherigo is officially supported on Android, iOS, and the discontinued Garmin Colorado and Oregon units. While you could possibly load the cartridges into an emulator of sorts, there will be no support given from me if you do so.
